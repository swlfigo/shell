Termes 是一款支持 **macOS、iOS 和 iPadOS** 的 SSH / SFTP 客户端。在 Vaults 中管理主机，用标签和分屏同时处理多个会话，浏览文件、查看 Linux 服务器状态，把常用的远程操作集中在一个工作区。

## 功能

### 主机与密钥管理

- **Hosts** 集中展示已保存的服务器，可按名称、地址或用户名搜索；Mac 支持卡片与列表视图，双击连接，iPhone 和 iPad 轻点主机即可连接。
- 支持密码、私钥和带口令的私钥登录；在 **Keychain** 中导入、重命名、替换和复用私钥，查看关联主机与指纹。
- 支持多级 SSH 跳板机，连接需要经过入口服务器访问的内网主机。
- 首次连接时确认服务器指纹；指纹变化时阻止连接，并显示原因。

### 终端与多会话工作区

- 通过标签和分屏同时操作不同服务器，可调整分屏比例、最大化窗格；Mac 和 iPad 还支持多个窗口及跨窗口移动会话。iPhone 和窄窗口通过切换窗格使用同一分屏布局。
- 切换标签、返回 Vaults 或收起工具面板时，保留当前会话和已输入内容。
- 支持复制粘贴与历史输出滚动；阅读历史时，新输出通过提示条提醒，点击即可回到底部。
- 搜索当前终端与保留的历史输出，高亮匹配并跳转，支持上一个 / 下一个和匹配计数。三端均支持中文及大小写不敏感的文本搜索。
- 将当前终端缓冲区中仍保留的输出导出为 UTF-8 纯文本，按终端折行保存；Mac 选择文件保存，iPhone 和 iPad 通过共享菜单存储到“文件”或分享。
- 意外断线后自动尝试重连，可查看连接阶段与日志，也可立即重试或取消。

### SFTP 文件管理

- 浏览本机和远端目录，上传、下载文件及整个文件夹；Mac 可在终端旁打开文件工具，iPhone 和 iPad 从“会话操作 → 文件”进入。
- 传输队列显示进度，支持暂停、继续、重试和取消，普通文件支持断点续传。
- 新建远端目录、重命名、删除条目，以及查看和修改文件权限。
- 直接编辑远端 UTF-8 文本文件并保存回服务器；有未保存内容时提醒，也可将草稿另存到本机。

### 服务器状态监控

- 在 Mac 的 **工具 → 概览** 或移动端的 **会话操作 → 服务器监控** 查看 Linux 服务器的 CPU、内存、磁盘、网络、负载和运行时长，无需额外安装监控程序。
- 查看最近 1、5 或 15 分钟的趋势，按网络接口查看流量，随时暂停或恢复采样。
- Mac 收起工具面板后保留监控历史；iPhone 和 iPad 关闭监控页后暂停采样，最近 15 分钟的历史保留在当前会话内存中，重新打开时继续采样。

### 端口转发与代理

- **本地转发**：通过当前设备上的本地端口访问服务器或内网中的服务。
- **远端转发**：让服务器通过指定端口访问当前设备上的本地服务。
- **SOCKS5 代理**：让支持代理的应用通过 SSH 服务器访问目标地址。
- 在 **Port Forwarding** 中保存和编辑规则，连接后手动启动，随时查看状态与停止转发。

### 常用命令与脚本

- 在 **Snippets** 中保存常用命令和多行脚本，按分组整理。
- 使用参数模板复用相同操作，插入前填写本次需要的参数并预览内容。
- 命令插入当前终端后等待按回车执行，方便再次检查目标和内容。

### 外观定制

- 支持跟随系统、浅色和深色界面，以及多种终端配色主题。
- 调整等宽字体、字号和默认文字颜色，通过即时预览选择适合自己的阅读方式。

## 开始使用

项目支持以下运行环境，仍在开发中，当前通过源码运行：

| 设备 | 系统要求 |
| --- | --- |
| Mac | macOS 13 或更新版本 |
| iPhone | iOS 17 或更新版本 |
| iPad | iPadOS 17 或更新版本 |

项目以 **Swift 6.4 编译器和 Swift 6 语言模式**作为构建与验收基线，`.swift-version` 记录当前验收版本 6.4.1。包清单的 `swift-tools-version` 仅声明清单工具版本下限，编译验收仍需实际选择 6.4 编译器。先安装 [Swift.org 官方工具链](https://www.swift.org/install/macos/)，在 Xcode 中选择该工具链；命令行构建前也需选择它并核对版本：

```sh
export TOOLCHAINS='org.swift.641202610071a com.apple.dt.toolchain.XcodeDefault'
xcrun swift --version # 应显示 Swift 6.4.1
```

在 Mac 上打开 `Termes.xcodeproj`，选择 **Termes** Scheme 运行 Mac 版，或选择 **TermesMobile** Scheme 在 iPhone / iPad 模拟器或真机上运行。Mac 版也可通过 `swift run Termes` 启动。移动端的签名与测试说明见 [iPhone 与 iPad](#iphone-与-ipad)。

本机日常使用可运行 `./scripts/build-macos-release.sh`，生成经过开发证书签名的 Release 应用及 ZIP，输出到 `build/release/`。将其中的 `Build/Products/Release/Termes.app` 放入 `/Applications` 后启动。脚本需要本机已有有效代码签名证书，首次选择证书后，会在忽略提交的 `build/release/signing-identity` 中记录指纹，后续构建复用；也可通过 `TERMES_SIGNING_IDENTITY` 指定证书的 SHA-1 指纹。请保留该记录，或继续指定相同签名身份。

旧版本保存的凭据首次由新签名应用访问时，macOS 可能要求输入 Mac 登录密码；选择“始终允许”后，后续相同签名身份的版本可沿用授权。Xcode 的默认本地临时签名以及 `swift run` 生成的可执行文件不保证跨构建沿用钥匙串授权，日常连接建议使用安装到“应用程序”的签名版本。

1. 打开 Termes，在 **Vaults → Hosts** 新建主机；移动端轻点列表右上角的 **+**。
2. 填写名称、主机地址、端口和用户名，选择密码或私钥；需要时设置跳板机。
3. 保存连接并点击 **连接**，首次连接时核对服务器指纹。
4. 连接后使用终端，Mac 通过 **工具 → 文件 / 概览**，iPhone 和 iPad 通过 **会话操作 → 文件 / 服务器监控** 打开对应工具。需要连接其他主机时，可随时返回 Vaults。

## 后台运行与会话恢复

macOS 的窗口与退出行为：

| 操作 | 行为 |
| --- | --- |
| 点击黄色最小化按钮 | 最小化窗口，连接和任务继续运行。 |
| 点击红色关闭按钮 | 将窗口收起到后台，保留会话、传输和端口转发。 |
| 点击 Dock 图标 | 恢复原窗口和会话。 |
| 关闭会话标签或窗格 | 有活动连接时先确认，再断开对应会话。 |
| 按 ⌘Q 退出 | 有未结束工作时，可选「后台运行（保持连接）」「断开并退出」或「取消」；没有任务时直接退出。 |

iPhone 和 iPad 切换会话或返回主机列表时保留连接与输出；进入后台后，iOS / iPadOS 可能暂停应用，终端、传输和端口转发不能保证持续运行，返回前台后需要检查连接状态。

重新启动应用时，会恢复窗口、标签、分屏布局和连接草稿，需要手动重新连接。终端输出、传输队列、监控历史和未保存的编辑内容不会跨重启保留。

## 快捷键

以下快捷键支持 Mac 和配备外接键盘的 iPhone / iPad；编辑表单打开时，移动端暂停处理工作区快捷键。

| 快捷键 | 操作 |
| --- | --- |
| ⌘T | 新建连接标签 |
| ⌘N | 新建窗口（Mac / iPad） |
| ⌘W | 关闭当前会话窗格；在 Vaults 首页收起窗口 |
| ⌘D | 复制当前会话到新标签 |
| ⌘1 … ⌘9 | 切换标签 |
| ⌘⇧[ / ⌘⇧] | 上一个 / 下一个标签 |
| ⇧⌘H | 返回 Vaults 首页 |
| ⌥⌘F | 搜索主机 |
| ⌥⌘I | 展开或收起服务器工具（Mac） |
| ⌘, | 打开外观设置 |
| ⌘F | 搜索终端历史 |
| ⌘G / ⇧⌘G | 下一个 / 上一个匹配 |
| Esc | 关闭终端搜索，搜索关闭时保留终端原有按键行为 |
| ⇧⌘E | 导出当前终端输出 |

移动端的 ⌘T 会打开主机选择页，并创建独立会话；数字键与上一个 / 下一个快捷键按标签切换，保留分屏标签内的焦点。

## 本地数据与导入导出

连接信息保存在当前设备本机，密码、私钥及私钥口令保存在该设备的系统钥匙串中。支持在 Mac、iPhone 和 iPad 之间导出和导入连接列表，导出文件不包含密码、私钥内容或口令；导入到新设备后，需要重新补充凭据。当前不自动同步各设备的数据。

## 当前状态

- 提供 macOS、iPhone 和 iPad 应用（移动端需要 iOS / iPadOS 17 或更新版本）。移动端已接入主机与密钥管理、SSH 终端、SFTP、端口转发、Snippets、服务器监控和工作区恢复，详见下方说明。跨设备云同步仍在规划中。
- 服务器状态监控目前支持 Linux。
- 中文历史日志在反复调整窗口宽度时出现空白或错位的问题，已通过升级官方 SwiftTerm 版本修复。依赖跟踪与回归验收见 [TODO](TODO.md)。

## iPhone 与 iPad

在 Xcode 中打开 `Termes.xcodeproj`，选择 **TermesMobile** Scheme，在 iPhone 或 iPad 模拟器上运行。真机运行需要在该 Target 的 Signing 设置中选择自己的开发团队。

移动端界面使用 **UIKit + SnapKit**，通过 `UISplitViewController` 和 `UINavigationController` 适配设备尺寸，终端使用 SwiftTerm 的 UIKit 视图，与 macOS 共用 `TermesKit` / `SSHCore`：

- iPhone 使用主机列表与终端之间的单栏导航，iPad 使用可收起侧栏的双栏工作区，支持横竖屏和窄窗口。iPad 可新建多个窗口，在窗口之间移动会话。
- 新建、搜索、编辑和删除主机；支持密码、导入私钥、复用已存私钥和跳板机。编辑时默认保留已有凭据。
- 首次连接核对主机指纹，查看连接阶段与日志，取消连接、断开和重连。
- 长按主机可以打开多个独立会话。切换会话或返回主机列表保留连接与终端输出；关闭活动会话需要确认。
- 在“会话操作”中复制标签，将其他标签合并到右侧或下方分屏，拖动分隔条调整比例，也可最大化窗格或移回独立标签。iPhone 和窄窗口显示当前窗格，顶部切换其他窗格；恢复宽度后保留原分屏布局。
- 编辑主机配置后会打开新会话，原会话保留原来的目标与终端输出。
- SwiftTerm UIKit 终端支持文本选择、复制粘贴、历史滚动、外接键盘，以及屏幕键盘上的 Esc、Tab、Ctrl 和方向键。旋转屏幕和显示键盘时同步调整远端终端尺寸。
- 在“会话操作 → 搜索终端历史 / 导出终端输出”中搜索或保存当前缓冲区。搜索在本机进行，搜索框中的输入不会发送到服务器；配备外接键盘时可使用 ⌘F、⌘G 和 ⇧⌘E。
- 查看终端历史时收到新输出，会显示“有新输出 · 回到底部”浮层；轻点后继续跟随最新输出，保留当前输入和键盘状态。
- 在终端顶部点图表图标，或选择“会话操作 → 服务器监控”，查看 Linux 服务器的 CPU、内存、磁盘、网络、Swap、负载和系统信息。支持最近 1、5、15 分钟趋势、网络接口选择，以及暂停、恢复和重试。后台暂停采样，回到前台时保留手动暂停的选择；关闭监控页面后暂停采样并释放采样连接，最近 15 分钟的历史保留在当前会话内存中，重新打开时继续采样。关闭会话或退出应用后清空。
- 在“会话操作 → 文件”中浏览远端目录，新建目录、重命名、删除空目录或文件，编辑 UTF-8 文本和 Unix 权限。保存文本时检查远端冲突，支持导出未保存草稿。
- 从系统“文件”选择文件或整个文件夹上传，下载到应用内的 Downloads。传输队列支持暂停、继续、重试、取消和普通文件断点续传；关闭文件页面后保留任务。可浏览本机文件、再次上传，或通过共享菜单存储到其他位置。导入的上传源保留在 Imports，可从“文件”App 管理。
- 在“资料库 → 端口转发”中离线保存本地转发、远端转发和 SOCKS5 规则，在已连接会话中手动启动、停止并查看状态；断开时停止转发，重连后手动启动。
- 在“资料库 → Snippets”中管理命令、多行脚本和分组。在“会话操作 → 插入常用命令”中填写模板参数并预览，插入当前会话后按回车执行。
- 在“资料库 → Keychain”中导入、重命名、替换和删除私钥，查看指纹及关联主机；共享私钥替换前显示受影响主机，正在使用的私钥不能删除。资料库也支持与 Mac 互通的主机元数据导入导出。
- 自动保存窗口、标签、分屏比例、焦点和最大化状态；重启后恢复布局，手动重新连接。终端输出、传输任务、监控历史和编辑草稿不会跨重启恢复。无法读取的工作区保留原文件，可在资料库中显式保存并备份旧文件。
- 调整界面外观、终端主题、字体、字号和文字颜色，立即应用到已有终端。内置 Source Code Pro 字体。

主机元数据保存在应用沙盒内，凭据保存在当前设备的钥匙串中。iOS 在后台可能暂停应用，终端、传输和转发不能保证持续运行；返回前台后需要检查连接状态。监控历史仅保存在会话内存中，不写入数据库或磁盘。

可以通过 Scheme 的 Test 操作运行移动端模型测试和 UI 测试，也可以使用命令行：

```sh
SWIFT_EXEC_MANIFEST="$(xcrun --toolchain com.apple.dt.toolchain.XcodeDefault --find swiftc)" \
xcodebuild -project Termes.xcodeproj -scheme TermesMobile \
  -destination 'platform=iOS Simulator,name=iPhone 17' test
```

在 Xcode 26.6 中，以上变量让包清单使用 Xcode 自带的清单编译器解析，避免自定义工具链的链接器查找错误。应用、共享模块和测试源码仍使用前面选定的 Swift 6.4.1 编译器与 Swift 6 语言模式。

可选的 SSH UI 集成测试使用仅监听本机的 `Tests/TermesMobileUITests/ssh_fixture.py`（需要 Python 的 `paramiko` 包）。先运行该脚本，再为上述命令加上 `TERMES_SSH_TEST_PORT=37937`，即可验证指纹确认、终端输入、屏幕旋转、会话保留、新输出提醒、服务器监控、SFTP 编辑下载及 Snippets 插入；未指定端口时会跳过这些集成测试。测试服务仅回显测试命令、模拟 Linux 监控数据，并在独立临时目录中提供 SFTP，不执行本机 shell。
